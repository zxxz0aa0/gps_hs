# GPS 軌跡查詢系統開發文件

## 專案目標
建立一個高效能的 GPS 軌跡查詢系統，能夠快速查詢和分析設備的歷史位置資料。使用者將EXCEL檔案上傳，系統會解析檔案並將資料存入資料庫，再透過前端介面查詢和分析資料。

## 技術棧
- **Backend**: [Laravel]
- **Database**: [MySQL]
- **Frontend**: [Vue.js]
- **前端MAP**: [Google Map]

## EXCEL檔說明
以下為GPS文件檔EXCEL格式，裡面有以下針對檔案進行說明：
第1行為列表名稱：紀錄列表
第2行為：查詢區間: 2024-11-01~2024-11-30          車牌及駕駛人TDA-6100,高義程8827
第3行開始為標題列，下方為範例，並包含標題行以下欄位：
| 定位時間 | 位置 | 速度 | 狀態 | 累計時間 | 地標 | 公里數 | 經度 | 緯度 |
| 2024-11-01 06:46:40 | 新北市中和區景平路171號 | 0 | 正常 | 1時59分 | - | 0 | 121.512| 24.99233 |
| 2024-11-01 06:47:10 | 新北市中和區安樂路32號 | 0 | 正常 | - | - | 0 | 121.5119| 24.99235 |
...

底下有多個工作表，每個工作表代表每一天，工作表名稱為日期，日期格式為2024-11-01，所有內容都跟上面一樣。

## EXCEL檔案要匯入到資料庫的資料說明
1.讀取的時候要從工作簿第一個工作表開始
2.讀取的時候要從工作表第二行須要車牌號碼（TDA-6100）、姓名（高義程）、車隊編號（8827）
3.要記錄的欄位有：定位時間、位置、經度、緯度
4.定位時間裡有日期跟時間，要將日期與時間拆開為日期與時間分別儲存至資料庫


## 功能說明
1.地圖顯示
2.查詢功能
3.地圖上顯示軌跡，軌跡顏色為橘色，使用資料庫經緯度並畫成線
